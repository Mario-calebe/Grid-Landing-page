# grid-Landing-page
Solução do projeto do Frontend Mentor

## Visão geral

### Sobre o desafio
Os usuários devem ser capazes de:

- Visualizar o layout ideal da página de acordo com o tamanho da tela do dispositivo
- Ver os estados de *hover* (passar o mouse) e *focus* (foco) de todos os elementos interativos da página
- Abrir e fechar o menu de navegação em qualquer tamanho de tela (JavaScript opcional)
